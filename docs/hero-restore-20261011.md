# Исходный первый экран с устройствами

11 октября 2026. История промежуточного восстановления. Финальные изменения после просмотра владельцем: `release-20261011.md`. В итоговом варианте одна кнопка, оба устройства показывают Mentori, подпись убрана, фон и футер обновлены.

## Запрос и реализация

- Исходные заголовок «Excel угробит развитие вашего бизнеса», описание и две кнопки взяты из `src/hero.html` версии `1f61bf2`.
- Live-панель заменена изображением ноутбука Mentori и телефона с сайтом «Спектра Металла». Это уже существующая визуализация `assets/hero/order-and-growth-1200.webp`.
- До 800px показывается телефон с демонстрационным экраном проектов `assets/services/projects-phone.webp`, не рабочая база.
- Однократное появление за 0,65 с, только при `prefers-reduced-motion: no-preference`. Нет бесконечных циклов, наклона, пролётов и связи со скроллом. Содержимое экрана статично, не выдаётся за работающий кабинет.
- Новый студийный фон и предыдущие слоганы отключены. Изображения и резервная копия сохранены, не удалены.
- Новые нижние блоки, четыре карточки с иллюстрациями, обложки услуг и вся страница «Что делаем» сохранены.
- CSS первого экрана: `hero-focus.css?v=20261011-2`. Сборщик использует `src/hero.html`.

Перед изменением создана копия `/Users/mentori/Mentoritech/backups/hero-before-restore-20261011` с исходниками, HTML и патчем предыдущей незавершённой итерации.

## Проверки

`npm run build` и `npm run check` успешно завершены: 13 страниц, 439 локальных ссылок/ресурсов, карточки, меню, услуги, цены, контакты и reduced-motion guards.

Браузерная проверка: 1280 x 720, 390 x 844 и 320 x 640. Горизонтального переполнения нет; на десктопе виден ноутбук с телефоном, на мобильных только телефон. На 390 x 844 следующий заголовок начинается на 778px, основные кнопки видны без прокрутки. Проверен переход «Что войдёт в систему» на `/services`, где сохранены шесть предложений. Снимки: `docs/qa-hero-20261011/`. Это проверка адаптивной ширины в браузере, не тест физического iPhone.

Сравнение с `345c60b`: блоки `#services`, `#directions`, `#subscription`, футер и весь `services.html` совпадают побайтно после извлечения блоков. Текущий прод не изменялся; доступность публичного сервера в этой итерации не проверялась.
