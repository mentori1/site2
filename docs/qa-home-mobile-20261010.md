# Проверка первого экрана и обложек

10 октября 2026. Локальный предпросмотр `http://127.0.0.1:4323/`. Изменения не публиковались.

## Автоматические проверки

- `npm run build` и `npm run check`: 13 страниц, локальные ссылки и изображения, JSON-LD, контакты, портфолио, меню, текущие цены.
- Единственная кнопка первого экрана, статичное изображение, отсутствие прежней анимированной таблицы и загрузочной заставки на главной.
- Нет таймеров старого сравнения Excel; логика однократного появления сцен нижних карточек сохранена и отдельно проверена.
- На обложках нет повторной цены. Цена в описании и данных каталога совпадает, цвет `rgb(255, 100, 29)`.
- Полные обложки используются в обоих разделах: на главной и в услугах.
- Повторная сборка не меняет байты готовых страниц, sitemap и общего JavaScript.

## Браузерная проверка

Codex In-app Browser, реальная отрисовка страницы с изменением размеров viewport. Это не физический iPhone и не отдельный запуск Safari.

| Viewport | Результат |
| --- | --- |
| 320 x 640 | Нет горизонтального переполнения. CTA виден, устройства не обрезаны; компактный отступ перед следующим разделом. Превью услуг по 213px. |
| 390 x 844 | CTA заканчивается на 407px, следующий заголовок начинается около 769px. Изображение загружено. Превью услуг по 260px. |
| 430 x 932 | CTA заканчивается на 365px, следующий раздел около 753px. Превью услуг по 287px. |
| 768 x 1024 | Нет переполнения. Следующий раздел около 804px. Превью услуг по 512px. |
| 1280 x 720 | Первый экран около 656px, следующий заголовок начинается около 696px. |
| 1440 x 950 | Первый экран около 844px, следующий заголовок около 884px. Все шесть обложек главной по 302px, тизеры по 398px. |

На странице услуг при 1440px: каждая пара карточек одинаковой высоты (959, 1104, 1104px), все превью по 444px. На телефоне карточки идут одной колонкой и могут иметь разную полную высоту из-за разного состава текста; высота превью одинаковая.

Кнопка «Обсудить мой бизнес» проверена переходом: открываются `/contact`, Telegram, MAX, почта и текущий номер `+7 999 669-34-19`. Отправки сообщений и звонков не выполнялись.

Обложка «Занятия и студии» на главной открывает `/services#studio`. Состав услуги раскрывается и закрывается. В журнале браузера после этих действий ошибок и предупреждений нет.

В мобильной карусели кнопка «Следующая карточка» переключает 01/04 на 02/04. Активна только вторая карточка, её иллюстрация появляется; скрытые третья и четвёртая не запускаются заранее.

Сравнение с предыдущим локальным коммитом подтверждает: разметка `#services`, `#subscription`, шапки и футера совпадает. Контроллер нижних анимированных сцен также совпадает; удалён только контроллер старой таблицы первого экрана. Изменён лишь верхний отступ перед разделом на широком и очень коротком экране, чтобы оставить видимым начало следующего блока.

Снимки сохранены рядом в `qa-home-mobile-20261010/`. Небольшая разница координат возможна во время однократного появления заголовка следующего раздела.

## Ограничения

Не выполнялись публикация, изменения DNS/TLS, проверки доступности из РФ, новый PageSpeed и проверка кэша предпросмотров мессенджеров. Эти изменения не требуют редактирования рабочей CRM или данных клиентов.
