# Исправление просвечивания карточек

Причина: общий стеклянный стиль заменял непрозрачный фон `.stack__card` на `rgba(255,255,255,.045)`, а GSAP дополнительно снижал opacity целой карточки до 0.5. При наложении через неё читались сразу несколько слоёв текста.

## Изменение

- Для `.services-stack .stack__card` восстановлена непрозрачная заливка `var(--bg-elevated, #111110)` и убран backdrop blur.
- Из desktop-анимации удалено только изменение `opacity`. Прежнее уменьшение масштаба до 0.94, sticky-позиционирование, отступы, размеры и скругления сохранены.
- Мобильная карусель не переписана. Исправление не меняет первый экран, тексты, меню, портфолио и замки.
- CSS: `20260925-stack`; JS главной: `58`.

## Проверки

- `npm run check`: 13 страниц, 399 ресурсов, тесты загрузчика и новый `tools/check-stack.mjs`.
- Тест подтверждает три desktop-анимации масштаба без opacity, отсутствие desktop-анимации на мобильном и при reduced motion, наличие непрозрачной заливки.
- На 1440 x 900, scrollY=2480: первые три карточки находятся на 100/116/132 px, четвёртая на 560 px. Все имеют opacity=1 и backgroundColor=rgb(17,17,16); первые две масштабированы до 0.94. Скриншот подтверждает читаемый третий слой без текста первых двух.
- При обратной прокрутке opacity остаётся 1.
- На 390 x 844 нет горизонтального переполнения; активная карточка имеет непрозрачную заливку, стрелка переводит с 01 на 02. Прежняя карусель сохранена.
- Сравнение всех страниц с версией до исправления подтверждает неизменность основного содержимого, заголовков, шапки и футера; меняются только версии ресурсов.
