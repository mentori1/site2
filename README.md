## Локальный просмотр

Это статический сайт на HTML, CSS и ванильном JavaScript. Исходники остаются читаемыми, а опубликованные CSS и JavaScript собираются в облегчённые production-файлы. GSAP, ScrollTrigger и Lenis загружаются отложенно только на компьютере, где используются scroll-анимации; мобильная загрузка их не запрашивает.

```bash
python3 -m http.server 4321
```

Открыть: http://localhost:4321/

## Production-ресурсы

Главная подключает `home.min.css?v=74`, остальные страницы подключают `styles.min.css?v=74`. Все страницы подключают `main.min.js?v=47`. Исходники `styles.css` и `main.js` напрямую в HTML не используются.

После изменения исходников заново собрать production-файлы и поднять номера версий во всех HTML-файлах. Главный CSS очищается по фактически используемой разметке `index.html` и классам из `main.js`.

```bash
mkdir -p /tmp/mentorios-build-home
npx --yes purgecss@7.0.2 --css styles.css --content index.html main.js --output /tmp/mentorios-build-home
npx --yes clean-css-cli@5.6.3 -O2 -o home.min.css /tmp/mentorios-build-home/styles.css
npx --yes clean-css-cli@5.6.3 -O2 -o styles.min.css styles.css
npx --yes terser@5.44.0 main.js --compress --mangle --output main.min.js
```

Проверка:

```bash
rg -n 'main\.min\.js\?v=|(?:home|styles)\.min\.css\?v=' *.html
```

## Аналитика

Яндекс Метрика `111247225` загружается динамически только после принятия cookie-баннера. До согласия запрос к `mc.yandex.ru` не выполняется. Факт принятия хранится в `localStorage` под ключом `mentori_cookie_consent_v1` и содержит уникальный ID, дату и способ принятия.

Согласием считаются кнопка «Хорошо», взаимодействие с элементом сайта или прокрутка после 5 секунд. Переход по ссылке политики внутри баннера согласие не создаёт.

UTM-параметры и `yclid` хранятся до конца визита в `sessionStorage` под ключом `mentori_visit_attribution_v1`. Формы заявки на сайте нет, поэтому эти параметры используются только в рамках текущего визита и аналитики переходов. Отдельного серверного журнала у статического GitHub Pages нет.

`main.js` отправляет следующие JavaScript-события:

| Идентификатор цели | Событие |
|---|---|
| `click_telegram` | Переход в Telegram |
| `click_phone` | Нажатие на телефон |
| `click_email` | Нажатие на email |
| `cta_contact` | Нажатие кнопки «Консультация», другого CTA контакта или ссылки MAX |
| `blog_article_open` | Открытие статьи из блога |
| `article_read_50` | Прочитано 50% статьи |
| `article_read_90` | Прочитано 90% статьи |
| `article_cta` | CTA внутри статьи |
| `service_click` | Выбор услуги |

В Яндекс Метрике цели из таблицы созданы с типом `JavaScript-событие` и указанными идентификаторами. Автоцели Метрики работают дополнительно и не заменяют эти события.

- `sitemap.xml` содержит все публичные страницы и статьи.
- `llms.txt` описывает компанию, услуги, материалы и контакты для поисковых и AI-систем.

- Обход страниц по счётчику Метрики `111247225` включён.

После публикации новой статьи или важного изменения:

1. Обновить `lastmod` страницы в `sitemap.xml`.
2. Проверить, что страница открывается с кодом `200` по HTTPS.
3. Проверить canonical, title, description, H1 и внутренние ссылки.
4. Отправить URL на переобход в Яндекс Вебмастере.
5. Убедиться, что актуальный `sitemap.xml` принят Вебмастером.
