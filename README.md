## Локальный просмотр

Сборки нет. Это статический сайт на HTML, CSS и ванильном JavaScript с GSAP, Lenis и Vanta через CDN.

```bash
python3 -m http.server 4321
```

Открыть: http://localhost:4321/

Сайт поддерживает светлую и тёмную темы. Автовыбор следует системной теме, ручной выбор хранится в `localStorage` под ключом `mentra-theme`.

Не использовать логотип с чёрным прямоугольным фоном. Актуальные знаки:

- `assets/mentory-wordmark-transparent.png`
- `assets/mentory-composite-wordmark.svg` — композиционный знак для шапки с контурными буквами на заднем плане

На главной при загрузке показывается компактная фирменная заставка без видео: небольшой логотип MENTORI TECHNOLOGIES, анимированное открытие знака и тонкий индикатор запуска. Клавиша `Esc` закрывает заставку досрочно; при системном ограничении анимаций она не запускается. В шапке используется логотип MENTORI с небольшой подписью TECH справа.

В футере телефон, почта и Telegram показаны компактными иконками с доступными подписями. Декоративные плашки с мигающей точкой удалены с главной, страниц «Что делаем», «О нас» и блога.

## Аналитика

Яндекс Метрика `111247225` загружается динамически только после принятия cookie-баннера. До согласия запрос к `mc.yandex.ru` не выполняется. Факт принятия хранится в `localStorage` под ключом `mentori_cookie_consent_v1` и содержит уникальный ID, дату и способ принятия.

Согласием считаются кнопка «Хорошо», взаимодействие с элементом сайта или прокрутка после 5 секунд. Переход по ссылке политики внутри баннера согласие не создаёт.

UTM-параметры и `yclid` хранятся до конца визита в `sessionStorage` под ключом `mentori_visit_attribution_v1`. При отправке формы они передаются вместе с заявкой. Отдельного серверного журнала у статического GitHub Pages нет, поэтому ID, дата и способ cookie-согласия также прикладываются к заявке.

Форма отправляется только после обязательного согласия на обработку персональных данных. `main.js` отправляет следующие JavaScript-события:

| Идентификатор цели | Событие |
|---|---|
| `click_telegram` | Переход в Telegram |
| `click_phone` | Нажатие на телефон |
| `click_email` | Нажатие на email |
| `cta_contact` | Нажатие основной кнопки перехода к разбору |
| `blog_article_open` | Открытие статьи из блога |
| `article_read_50` | Прочитано 50% статьи |
| `article_read_90` | Прочитано 90% статьи |
| `article_cta` | CTA внутри статьи |
| `service_click` | Выбор услуги |
| `form_submit_success` | Форма успешно отправлена |

В Яндекс Метрике эти 10 целей созданы с типом `JavaScript-событие` и указанными идентификаторами. Автоцели Метрики работают дополнительно и не заменяют эти события.

## Индексация

- Основной домен: `https://mentorios.tech/`
- `robots.txt` разрешает обход сайта и указывает `sitemap.xml`.
- `sitemap.xml` содержит все публичные страницы и статьи.
- `llms.txt` описывает компанию, услуги, материалы и контакты для поисковых и AI-систем.
- Сайт подтверждён в Яндекс Вебмастере.
- Обход страниц по счётчику Метрики `111247225` включён.

После публикации новой статьи или важного изменения:

1. Обновить `lastmod` страницы в `sitemap.xml`.
2. Проверить, что страница открывается с кодом `200` по HTTPS.
3. Проверить canonical, title, description, H1 и внутренние ссылки.
4. Отправить URL на переобход в Яндекс Вебмастере.
5. Убедиться, что актуальный `sitemap.xml` принят Вебмастером.
